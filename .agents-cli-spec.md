# Agent Spec — Thrilled to Announce (`ta`)

## Overview

- **Agent Package Name**: `thrilled_to_announce` (`root_agent` in `thrilled_to_announce/agent.py`, `adk_app` in `thrilled_to_announce/app.py`)
- **HTTP Server Entrypoint**: `server.main:app` (`PORT=8080`, health probe `GET /healthz`, conversational UI at `GET /`)
- **Brand Mark & UX**: Minimal single-column LinkedIn-inspired conversational interface using the `#0a66c2` **`ta`** (*Thrilled to Announce*) badge and avatar on a `#f4f2ee` canvas (zero LinkedIn `in` icons, zero sidebars or telemetry drawers).
- **Mission**: Automatically classify every user message into `HUMAN_DAILY` (candid everyday language), `LINKEDIN_SPEAK` (corporate LinkedIn announcements), `STYLE_TWEAK` (wording-preference updates), or `PUBLISH_REQUEST` (feed publishing), translate in the appropriate direction, asynchronously persist user wording preferences across sessions, enforce NDA / anti-doxxing / PII guardrails, and halt publishing behind a code-enforced Human-in-the-Loop confirmation gate (`require_confirmation=True`).

## Multi-Agent Topology & Model Routing

- **`coordinator_agent`** (`LlmAgent`, `gemini-2.5-flash`): Classifies user intent via `detect_human_or_linkedin_style`, loads user preferences via `retrieve_wording_preferences`, saves preference updates via `save_wording_preference`, delegates translation turns to `conversion_pipeline`, and gates publishing via `publish_to_linkedin_tool`.
- **`conversion_pipeline`** (`SequentialAgent`):
  1. **`subtext_analyst_agent`** (`LlmAgent`, `gemini-2.5-pro`): Extracts career intent, subtext, idiom mappings, and LinkedIn trope signals.
  2. **`conversion_and_reaction_crew`** (`ParallelAgent`):
     - **`linkedin_converter_agent`** (`LlmAgent`, `gemini-2.5-flash`): Produces either a polished `LinkedIn Style` announcement or a 1-sentence `Plain English` decoding aligned with the user's `WordingPreferenceProfile`.
     - **`feed_reaction_simulator_agent`** (`LlmAgent`, `gemini-2.5-flash`): Simulates hiring-manager and recruiter feed perception to surface unintended career-risk signals.
  3. **`self_eval_auditor_agent`** (`LlmAgent`, `gemini-2.5-pro`): Validates candidate drafts with `score_tone_and_bridge_burn_risk` (`bridge_burn_risk_score <= 15`, character and hashtag limits, banned-word and emoji compliance) before returning the final response.
- **Global ADK Plugins**: `BridgeBurnAndNdaPolicyPlugin`, `IntentOutcomeTelemetryPlugin`, and `ReflectAndRetryToolPlugin` wired on `App` (`EventsCompactionConfig`, `ContextCacheConfig`, `ResumabilityConfig`).

## Example Use Cases

1. **`Human -> LinkedIn` Conversion (`HUMAN_DAILY`)**:
   - Input: `"I am tired of my current company and just wanted to find something not that boring"`
   - Output (`LinkedIn Style`, `Copy · Post to LinkedIn`): *"I've exhausted the growth opportunities in my current role and am actively seeking a more stimulating and dynamic environment for my professional development."*
2. **`LinkedIn -> Plain English` Decoding (`LINKEDIN_SPEAK`)**:
   - Input: `"Thrilled to announce that after 4 impactful years driving synergistic transformation, I'm stepping back to explore fractional advisory horizons!"`
   - Output (`Plain English`, `Copy` only): *"I got laid off (or quit without another job lined up) and I'm looking for full-time work—please DM me if you're hiring."*
3. **Async Style-Preference Memory (`STYLE_TWEAK` & Cross-Session Recall)**:
   - Tweak turn: `"Make it shorter, sound more human, and avoid stiff words like 'exhausted'—remember this for next time"` -> immediately rewrites draft, queues non-blocking `asyncio.create_task` persistence (`✓ Style preference saved`), and applies stored rules automatically in new sessions (`Using your saved style`).
4. **NDA & Safety Guardrail (`Confidentiality Check`)**:
   - Input referencing unreleased quarterly revenue or secret internal project codenames is blocked pre-generation with label `Confidentiality Check`.
5. **Code-Enforced Publishing Approval (`Post to LinkedIn?`)**:
   - Clicking `Post to LinkedIn` or requesting publication triggers `FunctionTool(publish_to_linkedin_feed, require_confirmation=True)`, returning `status="awaiting_human_confirmation"` and opening the 2-button `Cancel` / `Post` confirmation dialog.

## Tools Required

All 5 LLM-callable tools validate inputs and outputs against strict Pydantic v2 models (`ConfigDict(extra="forbid")`) in `thrilled_to_announce/schemas/contracts.py` (`PreferredFormat`: `paragraph`, `bullets`, `broetry`) and return structured `recoverable_error` dictionaries with `recovery_instructions` instead of raising unhandled exceptions:

1. `detect_human_or_linkedin_style` (`DetectStyleRequest` -> `DetectStyleResponse`)
2. `retrieve_wording_preferences` (`PreferenceLookupRequest` -> `PreferenceLookupResponse`)
3. `save_wording_preference` (`SavePreferenceRequest` -> `SavePreferenceResponse`)
4. `score_tone_and_bridge_burn_risk` (`ToneValidationRequest` -> `ToneValidationResponse`)
5. `publish_to_linkedin_feed` (`PublishFeedRequest` -> `PublishFeedResponse`, wrapped in `FunctionTool(..., require_confirmation=True)`)

Authentication uses Google Cloud IAM Application Default Credentials (`GOOGLE_GENAI_USE_VERTEXAI=TRUE`, `GOOGLE_CLOUD_PROJECT=YOUR_PROJECT_ID`) or `SecretManagerResolver` (`SecretManagerServiceClient.access_secret_version` reading `gemini-api-key`).

## Constraints & Safety Rules

- **Agent Constitution**: Root `CONSTITUTION.md` and `thrilled_to_announce/prompts/constitution.py` enforce `Persona`, `Role`, `Scope`, `Tone`, `Constraints` (`You must never...`), and `Tool Policy`.
- **Policy Guardrails**: `BridgeBurnAndNdaPolicyPlugin` blocks unreleased financial metrics, non-public project codenames, personal-address doxxing, harassment, and prompt-injection attempts.
- **Active PII Redaction**: `PiiScrubber` combines Google Cloud Sensitive Data Protection (`dlp_v2.DlpServiceClient.deidentify_content` when `ENABLE_CLOUD_DLP=TRUE`) with deterministic regex scrubbing (`[REDACTED_EMAIL]`, `[REDACTED_PHONE]`, `[REDACTED_SSN]`, `[REDACTED_SALARY]`, `[REDACTED_SECRET]`) across `structlog` JSON logs, model inputs, and SQLite / vector memory writes.
- **Structured Observability**: `structlog` JSON logging (enforced by an AST gate verifying zero standard-output print calls in `thrilled_to_announce/` and `server/`), paired `"phase": "INTENT"` and `"phase": "OUTCOME"` records via `IntentOutcomeTelemetryPlugin`, and OpenTelemetry `TracerProvider` with `CloudTraceSpanExporter` (`--trace_to_cloud` / `OTEL_EXPORT_TO_CLOUD=TRUE`).

## Success Criteria

- **26 / 26 Golden Evaluation Cases**: `100%` pass rate across Suites A–F in `eval/golden_dataset.json` via `python -m eval.run_eval` and ADK `eval/thrilled_to_announce.evalset.json` + `eval/test_config.json` (`AgentEvaluator` enforcing `tool_trajectory_avg_score` and `response_match_score` thresholds).
- **Automated Quality Gates**: `ruff check .`, `pytest`, Python AST zero-print check, secret/hygiene scan, and `terraform validate` executed in `.github` workflows (`ci.yml`).
